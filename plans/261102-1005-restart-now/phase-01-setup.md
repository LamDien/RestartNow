# Phase 01: Project Setup & Gradle Environment
Status: ✅ Complete
Dependencies: None

## Objective
Khởi tạo khung dự án Android Native tiêu chuẩn với Gradle Wrapper, cấu hình Android SDK trỏ tới `/opt/homebrew/share/android-commandlinetools`, khai báo dependencies và manifest.

## Requirements
- [x] Tạo cấu trúc thư mục `app/src/main/java`, `app/src/main/res`
- [x] Cấu hình `settings.gradle`, `build.gradle` root và `app/build.gradle`
- [x] Thiết lập file `local.properties` với đường dẫn SDK chính xác
- [x] Cài đặt Gradle wrapper sẵn sàng chạy dòng lệnh `./gradlew`
